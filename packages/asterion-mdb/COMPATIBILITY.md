# Compatibility

`asterion-mdb` supports Python 3.12, 3.13, and 3.14 and includes `py.typed`.
Version `0.1.0` is pre-1.0; APIs may evolve as XTCE and SCOS adapters test the
neutrality of the model.

Time scales are preserved as metadata. This release does not ship leap-second
tables or convert between UTC, TAI, GPS, and TT.
